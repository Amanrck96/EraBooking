# **App Name**: Era Booking

## Core Features:

- Service Catalog: Display available salon services with descriptions, durations, and prices.
- Real-time Availability: Calculate and display available appointment slots based on staff availability, existing bookings, and buffer times.
- Custom Time Input: Allow users to input a preferred appointment time and validate it against availability.
- Automated Notifications: Send email and SMS confirmations and reminders for bookings, reschedules, and cancellations.
- Admin Dashboard: Provide an admin interface to manage bookings, staff, services, and settings.
- Google Calendar Sync: Sync confirmed bookings to staff Google Calendars after OAuth consent.
- Smart Time Suggestions: Suggest alternative time slots to the user if the originally requested custom time is unavailable. LLM uses time and calendar tools.

## Style Guidelines:

- Primary color: Soft, muted purple (#A391C2), inspired by the 'trendy' and 'elegance' mentioned in the prompt. 
- Background color: Very light, desaturated purple (#F0EFF4). This keeps the color scheme analogous while maintaining separation of the text
- Accent color: Light, contrasting lavender (#C2A3B1).
- Body and headline font: 'Inter' (sans-serif), to emphasize Era Salon's modern, unisex appeal
- Use clean, minimalist icons for services and actions.
- Mobile-first responsive design with a focus on clear, tappable CTAs.
- Subtle Framer Motion micro-interactions for loading states and confirmations.
